토닥 홈으로

개인정보 처리방침

토닥(TODAK)은 서비스 제공과 개선에 필요한 정보만 처리하며, 이용자의 정보를 안전하게 관리하기 위해 노력합니다.

1. 어떤 정보를 이용하나요?

도자기 제작 및 저장

토닥은 회원가입 없이 이용할 수 있어요. 만든 작품과 작업 기록은 이용자의 브라우저에 저장되며, 다른 기기와 자동으로 연결되지 않습니다.

의견 보내기

이용자가 남긴 의견과 첨부 이미지, 접수번호, 페이지 경로, 화면 크기 등의 정보를 오류 확인과 서비스 개선에 사용합니다. 반복 요청을 제한하기 위해 접속 IP를 변환한 값을 사용할 수 있습니다.

이미지 검색

'닮은 도자기 찾기'를 이용하면 작품 이미지가 외부 이미지 검색 서비스로 전송됩니다.

홈 조회수

홈이 열린 횟수만 한국 시간 기준으로 날짜별 집계합니다. 홈을 열면 Supabase에 HTTPS로 집계 요청을 보내며, 쿠키와 방문자 식별자는 보내지 않습니다.

2. 얼마나 보관하나요?

  • 작품 정보: 이용자의 브라우저에 저장되며, 브라우저 데이터를 삭제하면 사라질 수 있습니다.
  • 의견 및 첨부 이미지: 접수일로부터 최대 3개월간 보관 후 삭제합니다.
  • 요청 제한: IP 변환값은 마지막 접수 또는 허용된 검색 후 48시간을 기준으로 삭제합니다.
  • 이미지 검색: SerpApi는 업로드 이미지를 최대 30일간 보관한다고 안내합니다.
  • 홈 조회수: 날짜별 합계를 통계로 보관합니다.

보관 기간이 끝나거나 더 이상 필요하지 않은 정보는 삭제합니다. 법령에 따른 보존 의무가 있는 경우는 예외로 합니다.

4. 홈 조회수와 브라우저 저장

조회수 집계에는 분석 쿠키를 사용하지 않습니다. 토닥은 작품과 설정을 유지하기 위해 브라우저의 저장 공간을 사용합니다.
