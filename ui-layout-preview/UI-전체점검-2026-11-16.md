# UI 전체 점검과 튜토리얼 홈 이동

홈 제목이 한 글자만 다음 줄로 떨어지고, 작은 화면의 도구가 고정된 되돌리기 줄과 하단 버튼 사이에서 잘렸다. 가로 화면과 PC에서는 작품 카드의 제목·닫기 버튼 위로 작업 헤더가 올라왔다.

수정한 동작:

- 홈 메뉴의 제목 크기와 자간을 화면 너비에 맞춰 한 줄로 정리했다.
- 터치 도구의 최소 높이 66px, 모서리 14px, 아이콘 영역 28px를 공통으로 맞췄다. SVG 내부 비율은 유지한다.
- 하단 도구 패널에서는 도구 선택을 먼저 보여주고, 되돌리기는 해당 설정과 함께 스크롤한다. PC의 기존 배치는 유지한다.
- 작업 헤더보다 선택 화면과 작품 카드·진열장을 위에 표시해 제목·입력·닫기를 가리지 않게 했다.
- 튜토리얼 진행 카드의 ‘홈으로’는 안내를 잠시 멈추고 홈으로 이동한다. ‘튜토리얼 이어하기’로 같은 단계와 작품을 재개하며, ‘처음부터’와 일반 모드 진입은 기존대로 동작한다. 홈 이동을 완료로 기록하지 않는다.
- 기존 색상, 작품 정보와 보기의 통합 바, 색상 선택 중 항아리를 원래 밝기로 보여주는 동작은 유지했다.

검증:

- 26가지 화면 크기 × 12개 제작 장면: 312개 반응형 배치 검사 통과. 헤더 글자 높이 보정 후 경계 크기 21개 조합도 통과.
- 최종 화면 320×568, 390×844, 540×720, 768×1024, 844×390, 1440×900의 홈·제작 장면 72개: 글자 넘침, 홈 제목 줄바꿈, 초기 도구 잘림, 도구 높이·라운드 검사 통과. 실제 캡처로도 확인했다.
- 5개 화면 크기의 피드백·도전 선택·진열장·도움말·작품 카드 25개: 경계와 카드 제목 입력·닫기 검사 통과.
- 통합 바 10개 너비 × 3개 단계, 튜토리얼 안내 5개 화면 크기 × 14개 상태 통과. 항아리 외곽 마스크, 도구 모서리 일치, 바탕색 변경 픽셀, 말풍선과 작품의 겹침을 확인했다.
- 전체 튜토리얼 실제 행동 진행 조건, 홈 일시 정지·재개, 일반 제작→굽기→저장→360도 감상·재열기, 패널 끌기·접기·회전 후 상태 유지 검사 통과.

재현 스크립트: `tools/review-ui-shapes.cjs`, `tools/check-ui-details.cjs`, `tools/check-optional-tutorial.cjs`, `tools/check-tutorial-presentation.cjs`, `tools/check-work-bars.cjs`.

브라우저와 터치 에뮬레이션 기준이다. 모든 실제 휴대폰과 OS 공유창을 직접 검사한 것은 아니다. 사용자 첨부 파일과 화면 캡처는 공개 배포에 포함하지 않는다.
