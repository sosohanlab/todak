# 깎기 복구와 공방 안내 간소화

## 깎기

기존 모양 잡기·속 두께·매끈하게의 계산은 유지했다. 모양 잡기는 넓게 밀고 당겨 흙을 늘리거나 좁히고, 깎기는 좁은 바깥 표면의 흙을 빼기만 한다. 날 두께 2~14mm와 강도 5~100%를 독립적으로 조절한다. 기본값은 5mm·40%이며 다른 도구를 사용해도 유지된다. 최대 강도는 안쪽 이동량의 1/3, 기본 강도는 약 13.3%를 제거한다. 이전의 한 지점 0.35mm 고정 제한은 제거해 반복 손질로 기둥·굽·깊은 홈도 만들 수 있다. 누른 채 멈추거나 바깥으로 빼면 제거하지 않는다.

안쪽 벽과 높이·바닥을 옮기지 않으며 최소 벽 두께를 보호한다. 확대 상태에서는 같은 화면 이동이 더 작은 실제 이동으로 반영된다. 매우 빠른 포인터 이동도 놓치지 않도록 이동 이벤트에서 적용한다. 기존 작업 이력을 사용하며, 작은 깎기 후 두 손가락을 추가해 확대할 때도 의도한 손질을 지우지 않는다. 빚기 도구 네 칸에 맞춰 해당 버튼 행만 조정했다.

둥근 날의 영향은 윤곽 지점 사이까지 적분하므로 얇은 날이 지점 사이에서 헛돌지 않는다. PC의 같은 0.9cm 드래그에서 모양 잡기는 약 0.887cm, 100% 깎기는 약 0.292cm(약 32.9%), 40%는 약 0.117cm, 5%는 약 0.0146cm가 변했다. 날이 넓어질수록 손질 범위도 넓어지고 곡선 홈으로 이어진다. 기둥은 속 깊이를 줄여 아래쪽 흙을 채운 뒤 깎는 안내를 함께 표시한다.

## 튜토리얼과 유약·가마

36개 세부 행동을 5개 제작 단계 안의 7개 체크포인트로 묶었다. 빚기 도구, 꾸미기 도구통, 유약 도구를 묶어 소개한다. 도구를 직접 골라 사용하면 해당 제작 단계의 마지막 안내가 되고, 충분히 연습한 뒤 원래 단계 전환 버튼으로 이동한다. 연습 완료 후 PC 도구통을 숨기지 않아 다른 도구를 계속 사용할 수 있다.

중복 담그기 손잡이 버튼은 제거하고 슬라이더·작품 드래그는 유지했다. 바탕색·붓 유약·덧입힐 색을 같은 주요 8색으로 줄였으며 직접 색 고르기는 유지했다. 예전 색상 자료와 저장된 색 이름은 삭제하지 않았다.

불 세기 선택은 화면에서 제거하고 일정한 굽기를 사용한다. 새로 굽는 작품에는 무작위 색 변화·흐름·점·균열을 넣지 않고, 사용자가 고른 색·표면·무늬를 유지한다. 기존 저장 작품은 이전 재질 해석을 그대로 사용한다. 넣기/문닫기/굽기/식히기 시간은 총 약 9.05초에서 약 6.1초, 꺼내기 연출은 2.6초에서 1.9초로 줄였다. 실제 Chrome 검증에서 문 열기 준비까지 약 6.2~6.8초가 걸렸다.

## 검증

### 추가 요청: 색 입력·담그기·깨뜨리기 반응

물감·바탕 유약·붓 유약·덧입힐 색의 직접 색 선택과 코드 입력을 한 줄로 배치했다. 코드 입력을 덮지 않도록 실제 색 선택 영역도 왼쪽 버튼 안으로 한정했다. 담가서 덧입히기·표면 무늬는 접는 상자에서 일반 영역으로 꺼내고, 담그는 깊이 아래 설명을 제거했다. 안 함/담그기와 깊이·색·무늬의 기능은 유지했다.

깨뜨리기는 일반 작품과 저장 사진의 고해상도 계산을 유지하면서, 깨뜨리기 전용 형태만 669,696면에서 27,840면으로 줄였다. 조각 수 18개와 바깥색·그림·안쪽·파단면은 유지한다. 같은 소프트웨어 GPU 검사에서 조각 준비 계산은 약 7.3초에서 약 1.2~1.4초로 줄었다. 실제 창 열기 준비는 초기 그래픽 준비 상태에 따라 다르다. 드래그 동안은 준비한 원래 도자기 모습을 재사용하고, 포인터 이동은 화면 갱신마다 한 번만 그린다. 던지기의 벽 도달은 프레임 수 대신 실제 경과 시간으로 결정한다. 닫자마자 다시 열었을 때 이전 닫기 이벤트가 새 작업을 취소하지 않게 했다.

색 선택·코드 입력의 상호 반영과 한 줄 배치는 7개 화면에서 실제 클릭·입력으로 확인했다. 깨뜨리기는 Chrome 390/1440 화면에서 삭제 확인, 느린 이동과 닫기 시 원본 유지, 재열기, 실제 위쪽 던지기, 조각 저장 후 원본 삭제와 닫기를 검사한다. 검사 작품은 분리된 브라우저에만 만들고 외부 저장은 사용하지 않는다.

- 실제 Chrome의 320/390/830/1440/2560 화면: 날 두께 2/5/14mm와 강도 5/40/100%, 모양 잡기와 약 1/3 반응 비교, 실제 반복 드래그로 구슬 기둥·잘록한 받침·연결된 두 마디 기둥 만들기, 얇은 벽 보호와 대각선 손질.
- 390/1440의 자유 제작·도전: 도구별 작업 이력, 어떤 도구가 선택돼 있어도 정확한 되돌리기·다시하기, 단면 안쪽 오접촉 방지, 왼쪽 바깥벽, 확대 후 카메라 이동 없이 편집.
- 실제 터치와 미세 깎기 직후 두 손가락 확대 시 작업 보존.
- 8개 화면 크기의 묶음 튜토리얼: 실제 깎기·도장·팔레트·직접 색 지정·가마·저장·홈 복귀. 단계 마지막의 도구 접근과 말풍선 화면 경계를 확인한다.
- 기존 도구 전환 되돌리기, 7개 화면의 도구 행/사진/이력 위치, 4개 PC 화면의 회전 중 단계 전환 버튼 고정.
- 새로 굽기 전후 바탕색·덧입힐 색·직접 지정 색·윤곽·안쪽 벽·높이·바닥이 같은지 확인한다. 기존 고온 소성 색상도 이전 계산값으로 유지되는지 확인한다.

손빚기는 여전히 별도 미리보기다. 현재 물레·깎기는 회전 대칭 형태를 만든다. 꽃잎처럼 둘레마다 다른 형태는 향후 손빚기의 부분 변형이 필요하다. 기존 저장 작품의 형식이나 물레 해석은 이 작업에서 바꾸지 않았다. 손빚기 실제 추가 시에는 원본을 유지하는 별도 데이터 형식과 호환성 검증이 필요하다.

검증은 Chrome과 화면 크기 에뮬레이션 기준이며 모든 실제 기기·GPU를 검사했다는 뜻은 아니다.
