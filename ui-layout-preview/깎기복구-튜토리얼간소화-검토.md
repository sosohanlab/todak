# 깎기 복구와 공방 안내 간소화

## 깎기

기존 모양 잡기·속 두께·매끈하게의 계산은 유지했다. 깎기만 별도 모듈로 복구했다. 모양 잡기는 넓게 밀고 당겨 흙을 늘리거나 좁히고, 깎기는 좁은 바깥 표면의 흙을 빼기만 한다. 움직임으로 제거량을 정하며, 누른 채 멈추거나 바깥으로 빼면 제거하지 않는다. 한 손길로 한 지점에서 최대 반지름 0.035cm(0.35mm)만 제거한다. 위아래 긴 손길은 경로를 나눠 적분해 입력 빈도에 따른 차이를 줄였다.

안쪽 벽과 높이·바닥을 옮기지 않으며 최소 벽 두께를 보호한다. 확대 상태에서는 같은 화면 이동이 더 작은 실제 이동으로 반영된다. 매우 빠른 포인터 이동도 놓치지 않도록 이동 이벤트에서 적용한다. 기존 작업 이력을 사용하며, 작은 깎기 후 두 손가락을 추가해 확대할 때도 의도한 손질을 지우지 않는다. 빚기 도구 네 칸에 맞춰 해당 버튼 행만 조정했다.

실제 같은 0.9cm 드래그에서 손 모양 잡기는 약 0.85~0.88cm와 30개 윤곽 지점이 변했고, 깎기는 최대 0.035cm와 3개 지점만 변했다. 미세 손질과 전체 형태 변형의 차이를 확인했다.

## 튜토리얼과 유약·가마

36개 세부 행동을 5개 제작 단계 안의 7개 체크포인트로 묶었다. 빚기 도구, 꾸미기 도구통, 유약 도구를 묶어 소개한다. 도구를 직접 골라 사용하면 해당 제작 단계의 마지막 안내가 되고, 충분히 연습한 뒤 원래 단계 전환 버튼으로 이동한다. 연습 완료 후 PC 도구통을 숨기지 않아 다른 도구를 계속 사용할 수 있다.

중복 담그기 손잡이 버튼은 제거하고 슬라이더·작품 드래그는 유지했다. 바탕색·붓 유약·덧입힐 색을 같은 주요 8색으로 줄였으며 직접 색 고르기는 유지했다. 예전 색상 자료와 저장된 색 이름은 삭제하지 않았다.

불 세기 선택은 화면에서 제거하고 일정한 굽기를 사용한다. 새로 굽는 작품에는 무작위 색 변화·흐름·점·균열을 넣지 않고, 사용자가 고른 색·표면·무늬를 유지한다. 기존 저장 작품은 이전 재질 해석을 그대로 사용한다. 넣기/문닫기/굽기/식히기 시간은 총 약 9.05초에서 약 6.1초, 꺼내기 연출은 2.6초에서 1.9초로 줄였다. 실제 Chrome 검증에서 문 열기 준비까지 약 6.2~6.8초가 걸렸다.

## 검증

- 실제 Chrome의 320/390/830/1440/2560 화면: 흙 클릭·드래그, 모양 잡기/깎기/매끈하게 차이, 정지·바깥 이동 시 깎이지 않음, 최대 제거량.
- 390/1440의 자유 제작·도전: 도구별 작업 이력, 어떤 도구가 선택돼 있어도 정확한 되돌리기·다시하기, 단면 안쪽 오접촉 방지, 왼쪽 바깥벽, 확대 후 카메라 이동 없이 편집.
- 실제 터치와 미세 깎기 직후 두 손가락 확대 시 작업 보존.
- 8개 화면 크기의 묶음 튜토리얼: 실제 깎기·도장·팔레트·직접 색 지정·가마·저장·홈 복귀. 단계 마지막의 도구 접근과 말풍선 화면 경계를 확인한다.
- 기존 도구 전환 되돌리기, 7개 화면의 도구 행/사진/이력 위치, 4개 PC 화면의 회전 중 단계 전환 버튼 고정.
- 새로 굽기 전후 바탕색·덧입힐 색·직접 지정 색·윤곽·안쪽 벽·높이·바닥이 같은지 확인한다. 기존 고온 소성 색상도 이전 계산값으로 유지되는지 확인한다.

손빚기는 여전히 별도 미리보기다. 기존 저장 작품의 형식이나 물레 해석은 이 작업에서 바꾸지 않았다. 손빚기 실제 추가 시에는 원본을 유지하는 별도 데이터 형식과 호환성 검증이 필요하다.

검증은 Chrome과 화면 크기 에뮬레이션 기준이며 모든 실제 기기·GPU를 검사했다는 뜻은 아니다.
