# 점박이 경계 표시 수정

유약 미리보기의 2D 표면 무늬 투영에서 비어 있는 픽셀을 최대 8px 위로 채우던 처리가 가는 기둥과 급격하게 넓어지는 굽의 실제 표면 위쪽으로 넘어갔다. 점박이에서 갈색 점이 경계 밖의 선이나 잔상으로 드러났다.

각 높이의 흙 원판이 실제로 차지하는 타원 위쪽 경계까지만 빈 픽셀을 채운다. 무늬·도자기 형상·조작·화면 배치·저장 형식은 유지한다. 같은 투영 경로를 쓰는 붓칠과 담그기에도 올바른 경계를 적용한다. 기존 작품을 다시 표시할 때에도 적용되며 저장된 모양이나 그림을 지우지 않는다.

`tools/check-speckle-overlay.cjs`는 실제 몸통 원판과 입구 윗면을 독립된 마스크로 구성하고, 투영 텍스처가 경계 밖에 있는지 검사한다. 안티앨리어싱의 한 픽셀 범위는 허용한다. 구슬 기둥, 긴 기둥 잔, 고블릿, 호리병, 그릇을 모바일 390px 및 PC 1440px에서 점박이·잔금·담그기·붓칠로 검증한다. 점박이 해제 시 기존 텍스처도 남지 않는지 확인한다. 수정 후 모든 검사에서 경계 밖 텍스처 픽셀 0개를 확인했다. 실제 휴대전화 하드웨어가 아닌 Chrome 화면 크기/터치 설정 검증이다.
