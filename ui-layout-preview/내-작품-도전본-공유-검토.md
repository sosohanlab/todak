# 내 작품 도전 본과 공유

내 진열장에서 작품을 열거나 완성 화면에서 ‘이 작품으로 도전 본 만들기’를 누른다. 도전 선택 창 맨 위의 ‘내가 만든 도전’에서도 등록할 수 있다. 등록 순간 모양·높이·속 깊이를 별도로 복사하므로 원본 변경이나 삭제는 등록한 본에 영향을 주지 않는다. 사진만 남은 옛 작품은 보존하되 본 등록은 비활성화한다. 기본 도전 14개는 유지한다.

개인 도전은 새 흙에서 시작하며 모양 잡기 20회, 모양 평가 90점과 횟수 10점으로 평가한다. 처음 2회 이내는 횟수 10점이고 이후 남은 비율로 줄어든다. 원본의 얇은 접시·구슬 기둥·낮은 굽·속이 막힌 조형물도 각자의 형태를 기준으로 평가한다. 개인 도전은 원본을 재현하는 연습을 위해 무너짐과 무작위 거칠어짐을 적용하지 않는다. 기본 도전 규칙과 포인트 보상은 변경하지 않는다.

각 도전 카드의 ‘공유’에서 링크 또는 복사·붙여넣기용 코드를 전달한다. 코드는 약 350~500자의 모양 데이터이며 서버 조회용 짧은 번호가 아니다. 이름과 모양, 고정 규칙만 담고 원본 사진과 진열장은 전송하지 않는다. 공유 링크는 URL fragment에 코드를 담아 서버 없이 다른 브라우저에서도 불러온다. 공유받은 사용자는 미리보기 후 명시적으로 목록에 추가한다. 링크를 열거나 목록에 추가하는 동작은 하던 작품을 초기화하지 않는다. 같은 코드는 중복 등록하지 않는다. 손상된 코드, 잘못된 길이·버전·수치·문자열은 거부한다. CRC는 입력 손상 검사용이며 작성자 인증 수단은 아니다.

도전 본은 LocalStorage와 IndexedDB에 저장한다. 공유 링크 자체는 기기 저장소가 지워져도 남아 있는 코드에서 복원할 수 있다. 진행 중인 개인 도전에는 당시의 본도 함께 저장하므로 목록에서 본을 삭제해도 하던 작업은 이어갈 수 있다. 모두의 진열장 공개 기능과는 별개다.

검증: Chrome의 320·390·830·1440·2560px 화면, 모바일 터치 설정, 서로 저장소가 분리된 브라우저 컨텍스트에서 등록·원본 보존·별도 기기로 공유·재실행·작업 이어하기·중복/손상 코드 처리를 확인한다. 실제 휴대전화 하드웨어 검증을 대체하지 않는다. 별도 점수 단위 검증에서 일반 컵, 얇은 접시, 구슬 기둥, 고체 조형물의 일치 시 100점과 속/모양/높이/표면 불일치 감점을 확인한다. 기존 기본 도전 점수 검증도 유지한다.
