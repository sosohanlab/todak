# 최근 조작부터 되돌리기와 거침 표시 배치 수정

기존 되돌리기는 한 번 누른 뒤 뗄 때까지의 긴 조작을 전부 취소했다. 이제 캔버스에서 빚거나 꾸미는 동안 약 0.4초마다 실제로 바뀐 상태를 나눠 기록한다. 짧은 조작은 한 번으로 유지하고, 멈춰 있거나 도전 횟수만 바뀌면 같은 모양의 기록을 추가하지 않는다.

도전의 모양 잡기 횟수는 여전히 한 번 누르고 뗄 때까지가 1회다. 중간 되돌리기는 그 횟수를 유지하고, 해당 조작 전체를 되돌리면 횟수도 원래대로 복구한다. 다시하기는 같은 모양·물감 이미지·횟수를 복원한다. 최대 40개 기록과 이미지 타일 공유를 유지하며, 긴 접촉 중 버려진 기록을 별도 배열에서 붙잡지 않는다. 새 자유 작업이나 새 도전을 시작하면 이전 작업 기록을 비운다.

화면 찌그러짐은 `#ui-rough-row`를 작은 화면의 `#p-throw`로 옮긴 뒤에도 상단 바의 `grid-column:4;grid-row:1`이 적용되는 것이 원인이었다. 거침 점수가 생기면 도구 패널에 암시적 열 4개가 생겨 도구·되돌리기·치수가 세로로 눌렸다. 같은 삿갓 면기 조건에서 재현했다. 상단 바의 배치 규칙을 해당 바 안으로 한정하고, 도구 패널을 한 열로 명시했다.

확인한 내용:

- 320×568, 390×844, 768×1024, 844×390, 1440×900에서 거침 표시 켜짐→꺼짐→켜짐에 따른 패널 열·도구 너비·자식 경계 검사 통과.
- 모바일·PC 실제 긴 빚기·붓질·도전 드래그: 첫 되돌리기가 직전 구간만 취소하고, 전체 되돌리기와 다시하기가 원본·완성 상태를 정확히 복원하는지 통과. 도전 횟수도 검사했다.
- 짧은 붓질·조각·도장 6개 조합의 기존 1회 기록과 모든 이미지 레이어의 정확한 복원 검사 통과.
- 40개 이미지 기록, 기록 한도·분기·색상 선택·상하부 이미지 복원 검사 통과.
- 반응형 경계 21개, 튜토리얼 별도 진입·홈 이동·이어하기·일반 모드 진입 4개 화면 크기 검사 통과.

회귀 검사: `tools/check-recent-undo.cjs`. 수정 전 재현 캡처와 수정 후 결과는 로컬 `output/recent-undo/`에 저장하며 배포하지 않는다.
