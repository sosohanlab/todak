# 유약 튜토리얼 순서

바탕 유약 → 색 → 유광/무광 → 담그기 → 표면 무늬 → 붓 선택 → 붓 불투명도 → 붓칠 → 굽기 순서로 변경했다.

바탕색 설정을 한 번에 마치도록 ‘바탕붓으로 돌아가기’를 제거했다. 유약 안내는 9단계에서 8단계, 전체 안내는 38단계에서 37단계다. 붓칠이 유약 단계의 마지막 실제 조작이며, 칠한 뒤에는 ‘가마에 넣기’를 눌러 굽기로 이동한다. 바탕색·담그기·표면 무늬는 붓으로 전환할 때 유지된다.

실제 행동을 요구하는 기존 전체 튜토리얼 검사와 320×568, 390×844, 1440×900 브라우저에서 새 유약 순서·설정 유지·직접 붓칠·다음 단계 버튼을 확인했다.

재현: `tools/check-glaze-tutorial-order.cjs`, `tools/check-tutorial-flow.cjs`.
