# 버튼 조합 점검과 편집 보완

검사한 순서는 도구만 바꾸기, 도구를 바꾼 뒤 실제 편집, 전체/단면·옆면/위/밑바닥 전환, 색·표면·덧입힘 변경, 접기/열기, 도움말, 단계 왕복, 홈·도전·진열장·튜토리얼 복귀를 포함한다. 모바일과 PC의 통과한 시나리오를 합쳐 실제 버튼 클릭 2,426회, 상태 검사 2,818회, 시나리오 22개를 확인했다. PC 완성 화면은 3D 계산 시간을 반영해 해당 두 시나리오를 재검사했다. 모든 무한한 클릭 순열이나 실제 기기 전체를 검사했다는 의미는 아니다.

발견해 수정한 내용:

- 항아리 바깥에서 시작해 표면으로 들어온 깎기·매끈하게 조작이 되돌리기에서 빠졌다. 편집 시작 상태를 먼저 보관하고, 실제 변화가 없는 조작만 버리도록 수정했다. 선택한 도구가 무엇이든 최근 기록 한 단계만 되돌린다. 긴 조작의 약 0.4초 구간 기록은 유지했다.
- 이미 속이 있는 작품에서 속·두께를 선택하는 것만으로 안쪽 벽을 보정하던 동작을 제거했다. 처음 속을 파는 실제 변화와 초기 모양 명령은 별도 기록으로 남긴다.
- 모바일 빚기·꾸미기·유약에서 되돌리기/다시하기를 도구 선택 위에 배치했다. 짧은 화면에서도 첫 도구 줄이 잘리지 않게 높이를 맞췄다.
- 빚기는 이미지 없는 글자 버튼으로 정리했다. 꾸미기와 유약 도구의 이미지는 유지했다. 깎기 삭제는 확정 요청이 없어 보류했다.
- 빚기·유약에서도 PC 휠 확대를 허용했다. 실제 휠 확대 후 빚기와 꾸미기·유약의 옆면/위/밑바닥 편집이 되고, 편집 중 화면이 이동하지 않는 7개 흐름을 검사했다.
- 물감·바탕색·붓 유약·덧입힐 색에 큰 ‘원하는 색 고르기’ 버튼을 만들었다. 색상 코드 입력은 선택 항목으로 접었다. 고른 색 표시와 되돌리기/다시하기를 함께 동기화했다.
- 영어 화면에서 번역되지 않는 속성을 같은 값으로 반복 설정해 UI가 멈추던 번역 감시 루프를 수정했다. 공방 꾸미기, 포인트 부족 안내, 홈 복귀, 언어 왕복도 검사했다.
- 새 배치에 맞춰 모바일 튜토리얼 안내를 진행 카드 옆으로 옮겨 도구·접기 버튼을 가리지 않게 했다.

이전 진열장 가져오기:

- 신규 방문자는 가져오기 안내를 보지 않는다. 이전 작품이 확인되거나 이전 주소에서 작품이 있다는 안내와 함께 돌아온 경우에만 표시한다. 가져오기가 완료되면 다시 표시하지 않는다.
- 안내 표시 여부는 현재 진열장을 수정하지 않는다. 데이터 병합 방식은 유지했다. 중복 가져오기·빈 이전 진열장을 25회 섞어도 현재 작품과 가져온 작품, 색칠 데이터와 점수가 그대로 남는지 확인했다.
- 서로 다른 두 주소의 브라우저 저장소·팝업·조각 저장소를 사용해 실제 병합과 재접속 후 유지까지 검사했다. 이전 주소 iframe 저장소가 차단된 브라우저는 이전 주소 페이지의 새 사이트 링크로 돌아오는 경로를 제공한다.

최종 보완 검사: 모바일 도구 순서 7개 크기 × 3개 편집 단계, 시각적 색 선택 3개 너비 × 4개 입력, 도구 전환 후 복구 16개 조합, 확대 편집 7개, 반응형 경계 21개, 피드백 모의 실패/재시도 5개 크기, 진열장 병합·보존 검사. 외부 의견 전송은 모의 응답으로 처리했고 실제 의견을 보내지 않았다. 사용자 첨부 파일·작품 데이터는 배포 대상에 포함하지 않는다.
