# 튜토리얼 상황별 안내·담그기·카드 반응형 수정

## 완료 안내

### 추가 수정: 불필요한 확인 줄이기

단면·도장 모양·유약 도구/색/반짝임/무늬·불 세기 선택, 크기/불투명도/담그기 조절, 저장 요청, 창 닫기는 완료 뒤 자동으로 이어진다. 포인터를 누르고 있거나 슬라이더의 방향키를 누르는 동안에는 다음 단계로 이동하지 않는다. 빚기·그리기 연습은 더 해볼 수 있도록 수동 진행을 유지한다. 글 입력은 입력 완료, 사진과 검색은 내용 확인 버튼을 쓴다. 제작 단계 전환은 기존 꾸미러 가기/유약 바르기/굽기 버튼을 그대로 쓴다. 가마에 넣은 다음에는 추가 확인 없이 식히기 안내를 기다린다.

도구 사진 8개는 버전이 붙은 `tool-images.js`에 원본 WebP 데이터로 함께 넣는다. 개별 사진 요청 실패에 따른 깨진 이미지 아이콘을 방지하고, 캔버스 커서와 도구 선택이 같은 사진을 쓴다. 기존 크롭·비율·도구 사진은 유지한다. `check-tutorial-transitions.cjs`는 별도 사진 요청을 차단한 상태에서 8개 사진의 실제 디코딩/불투명 픽셀, 자동 선택 전환, 마우스·키보드 슬라이더 유지, 연습 대기, 가마 진행을 Chrome의 390/830/1440/2560 너비에서 확인한다.

모든 단계에 반복되던 ‘잘했어요! 더 연습해도 좋아요’를 제거했다. 실제 행동에 맞춰 단면 전환, 도장 모양 선택, 유약 붓 선택, 제목·용도 입력, 크기 조절, 저장·공유 요청 등을 구분한다. 저장 요청과 실제 파일 수신을 같은 의미로 표현하지 않는다. 실패한 저장 요청을 완료로 처리하던 경로도 제거했다.

완료 후에는 튜토리얼 딤드를 모두 해제한다. 빚기·그리기·유약 칠하기를 더 연습하거나 단계 전환 버튼을 기다리는 동안 작품과 도구를 밝게 볼 수 있다. 선택만 한 단계에는 조형 연습을 더 하라는 공통 문구를 사용하지 않는다.

## 완성 사진과 검색

가마 문 열기와 완성 사진 확인은 별개로 처리한다. 작품을 꺼내는 연출과 사진 렌더러 준비가 끝나고 실제 완성 화면을 그린 뒤 사진 확인 안내를 표시한다. 그 전에는 진행 카드·말풍선·딤드를 숨기며 튜토리얼의 360도 전환을 잠시 비활성화한다. 선택형 3D 렌더러가 실패하거나 오래 걸리면 기존 기본 보기의 실제 프레임을 준비한 뒤 이어갈 수 있다.

완성 사진이 기본으로 켜져 있다는 이유로 완료하지 않는다. 사용자가 ‘사진 확인했어요’를 눌러 확인한다. 전체 보기와 소리도 초기 선택 상태만으로 완료하지 않는다. 크기·불투명도는 진입 시 값과 실제로 달라졌는지 확인한다.

검색 버튼 클릭은 요청 시작일 뿐 완료가 아니다. 결과 목록, 결과 없음 또는 연결 오류 안내가 DOM에 나타난 뒤에만 다음 안내를 열며 결과를 둘러볼 수 있다. 이때 닫기 버튼으로 강조를 옮기지 않는다. 검색 중에는 딤드를 해제하고 기다리는 상태를 표시한다. 응답 전에 창을 닫았다면 완료하지 않으며 다시 열어 실제 내용을 볼 때 이어간다.

## 조작과 배치

- 크기 조절은 ‘− / 슬라이더 / ＋’ 전체를 하나의 조작 영역으로 강조한다.
- 담그기는 튜토리얼·자유 제작·도전 모두 ‘안 함 / 담그기’ 두 선택으로 통일했다. 깊이는 기존 슬라이더와 손잡이로 조절하며 껐다 켜도 마지막 깊이를 유지한다. 이전 입구만·절반까지 저장값은 담그기가 켜진 상태로 표시한다.
- 카드 창은 화면의 88% 너비를 기준으로 최대 1040px까지 커진다. 760px 이상에서는 카드 미리보기와 입력칸을 좌우로 배치한다. 작은 화면에서는 위아래로 정리한다. 검색·진열장 창도 화면에 비례하는 너비와 각각의 상한을 사용한다.
- 카드·검색 창에서는 진행 정보를 말풍선 안에 간단히 표시해 내용과 겹치지 않게 한다. ‘홈으로’는 계속 사용할 수 있다.

## 검증

`check-tutorial-context.cjs`는 390×844, 830×900, 1440×900에서 실제 클릭·입력·다운로드 요청을 사용한다. 사진 렌더러와 검색 응답을 의도적으로 지연시켜 성급한 완료를 차단하는지 확인한다. 보기·도구 선택, 제목·용도·저장 문구, 완료 뒤 딤드, 크기 조절 전체 강조, 세 모드의 담그기, 카드 너비·열 구성을 검사한다.

`check-tutorial-presentation.cjs`는 여러 크기에서 강조 영역과 말풍선 위치, 카드 창에서 홈 복귀·이어하기를 확인한다. `check-tutorial-flow.cjs`는 전체 단계 흐름을 검사하며 이 상태 검사에서는 WebGL 드라이버와 연출 완료를 대체한다. 실제 렌더링 대기 검사는 위 Chrome 검사에서 별도로 수행한다. 유약 단계 순서와 회전 중 다음 버튼 안정성도 회귀 검사한다.

브라우저 검사는 Chrome과 화면 크기 에뮬레이션 기준이다. 운영체제의 파일 저장 완료나 실제 모든 기기의 GPU 동작을 보증하는 검사는 아니다.
