# 채점 개편·깎기 제거·튜토리얼 클릭 수정

## 확인한 기존 문제

실제 이전 채점 함수를 대상으로 14개 목표를 조사했다. 바닥 위치만 낮추고 내부 반지름을 0으로 두거나 0.1cm의 작은 구멍만 만들어도 99~100점이 나왔다. 모양 잡기 사용량은 점수에 반영되지 않았다. 접시는 실제 표현 가능한 기준 형상 그대로여도 보간 차이로 옆선에서 감점될 수 있었다.

튜토리얼은 다음 안내 버튼을 장애물 목록에 포함해 자신의 이전 위치를 피하며 재배치하고 있었다. 회전·흔들림 중 PC 4개 크기에서 말풍선 위치를 추적했으며, 최대 약 1,058px 이동과 실제 클릭 실패를 재현했다. 기존 정지 화면 배치 검사로 확인하지 못한 결함이었다.

## 새 채점 v3

| 항목 | 배점 | 기준 |
| --- | ---: | --- |
| 옆선 | 40 | 실제 렌더링과 같은 보간으로 기준 형상과 비교. 평균·제곱평균·최대 오차를 함께 본다. |
| 높이 | 20 | 목표 높이의 상대 오차. 미세 입력·정수 표시 오차를 위한 작은 허용 범위를 둔다. |
| 속 완성도 | 15 | 입구부터 연결된 실제 깊이, 열린 공간의 비율, 벽과 바닥 상태. 바닥 숫자만 낮춰서는 만점이 나오지 않는다. |
| 매끈함 | 15 | 목표 형상 고유의 곡률을 제외한 안팎 잔굴곡. 벽 두께에 따른 자연스러운 안쪽 곡률 차이도 보정한다. |
| 남은 횟수 | 10 | 기본 2회까지 10점. 이후 남은 횟수의 비율로 계산한다. |

횟수 점수는 `반올림(10 × 남은 횟수 ÷ (제한 횟수 − 2))`를 0~10점으로 제한한다. 전체 제한을 모두 사용하면 0점이다. 도구를 선택하거나, 보기를 바꾸거나, 색·유약·가마 결과를 바꿔도 횟수 점수가 달라지지 않는다. 되돌리기·다시하기는 실제 형태와 함께 사용·남은 횟수를 복원한다.

현재 14개 물레 목표는 내부 공간이 필요하다. 입구가 막혔거나 내부가 거의 닫혀 있는 경우 총점 최대 59점을 적용하고 이유를 결과에 표시한다. 향후 꽉 찬 조형물이 목표인 도전에는 동일한 빈 그릇 규칙을 강요하지 않도록 목표의 내부 조건을 지원한다.

조작 횟수를 아껴도 형태 점수 90점을 대체할 수 없다. 반대로 횟수를 모두 사용해도 완성도가 높으면 최대 90점을 받을 수 있다. 명장 도전의 85점 기준은 현재 유지한다.

## 기준 형상으로 확인한 균형

14개 목표에서 정상 내부·기준 형상·기본 2회를 사용한 경우 100점, 모든 횟수를 사용한 경우 90점, 내부가 막힌 경우 최대 59점을 확인했다. 옆선 반지름을 전체적으로 10% 늘린 경우에는 목표에 따라 82~85점으로 낮아졌다. 의도적인 안쪽 잔굴곡도 매끈함 점수를 낮춘다.

이 숫자는 계산과 기준 형상 검사 결과다. 실제 사람의 난이도·숙련도 분포를 측정한 플레이 테스트를 대신하지 않는다. 손빚기의 작업량과 공개 순위 기준은 별도 설계안의 검증 절차를 따른다.

## 기록과 공개 순위 준비

- 새 최고 기록은 `_v3`로 구분한다. `_v2`와 이전 기록, 기존 진열장 작품의 점수를 삭제하거나 새 기준으로 덮어쓰지 않는다.
- 새 작품에는 제작 방식, 목표, 안내·외워서·명장 조건, 버전, 사용·남은 횟수, 항목별 점수와 원본 정밀도의 형상을 저장한다.
- 현재는 로컬 점수이며 검증 상태도 `local`로 기록한다. 실제 공개 순위는 서버 재계산·작업 기록 검증·목표 개정판 구분이 필요하다.
- 손빚기·물레·혼합 도전은 같은 숫자만으로 한 순위에서 비교하지 않는다. [손빚기·혼합 제작 설계안](손빚기-혼합제작-채점-설계안.md)에 구체적인 흐름과 채점 방식을 정리했다.

## UI와 도구

깎기를 기본 도구, 접힌 도구창, 벽 도구통, 튜토리얼에서 제거했다. 빚기는 **모양 잡기·속/두께·매끈하게** 3개로 맞췄다. 속 깊이 슬라이더와 안쪽 매끈하게는 유지한다. 튜토리얼은 36개 안내이며, 완료 후 직접 다음 안내를 누르는 방식을 유지한다.

완성 결과의 5개 점수 항목을 개별 칸으로 보여주고, 작은 화면에서 점수 내역이 저장 버튼 아래로 가려지지 않도록 결과창 높이를 조정했다. 횟수 점수와 실제 남은 조작 횟수는 구분해 표시한다.

## 튜토리얼 클릭 안정화

말풍선 자신의 버튼을 장애물 검사에서 제외했다. 동일한 단계·대상·화면 배치에서는 말풍선 위치를 다시 계산하지 않는다. 도자기의 강조 윤곽은 계속 움직이지만, 회전과 물리 흔들림이 클릭할 말풍선을 움직이지 않는다. 단계·화면 크기·도구창 스크롤·보기 전환처럼 실제 배치가 달라질 때만 다시 배치한다.

1024×768, 1280×720, 1440×900, 1920×1080에서 빚기·속/두께·붓·유약 안내의 완료 상태를 검사했다. 회전 중 좌표를 반복 측정하고 마우스를 이동한 뒤 누른 상태로 잠시 기다렸다가 떼는 실제 클릭을 수행했다. 수정 후 16개 상태 모두 이동 0px, 한 단계 진행 성공을 확인했고 우선 배포본에서도 검증했다.

## 검증

- 채점 단위 검사 12개: 14개 기준 형상, 횟수 단조성, 내부 막힘·작은 구멍·얇은 벽·얕은 내부, 높이·너비 오차, 렌더링 일치, 잔굴곡, 색·보기·가마 독립성, 비정상 입력, 무작위 입력 1,500개.
- 실제 화면: 7개 크기 × 14개 목표, 점수 내역·실제 조작·되돌리기·다시하기·기존 기록·새 저장 정보.
- 회전 중 안내창 고정·실제 클릭 16개 상태. 정지 배치·강조 영역 112개 상태.
- 반응형 26개 크기 × 12개 화면, 완성 결과의 작은 화면 6개 추가 검사.
- 3개 도구의 전환 후 복구 12개 조합, 모바일 도구 순서 21개 상태, 빚기 버튼 조합 122회 클릭.
- 튜토리얼 전체 실제 동작 흐름, 홈 복귀·이어하기, 터치 그리기·핀치·기존 획 보존, 제작부터 굽기·저장·재열기 확인.

자동 검사는 Chrome과 터치 에뮬레이션 기준이다. 실제 휴대전화의 운영체제 공유창과 실제 기기의 성능 검증은 별도 범위다.
