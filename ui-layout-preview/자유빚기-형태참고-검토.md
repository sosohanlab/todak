# 자유 빚기 형태 참고

홈에서 ‘자유롭게 빚기’를 누르면 처음 선택창이 열린다. ‘본 없이 자유롭게 빚기’를 누르거나 기본 14개 및 직접 등록/공유받은 개인 본 중 참고 형태를 고른 뒤 새 흙에서 시작한다. 선택창을 닫으면 하던 작업과 홈 상태를 그대로 유지한다. 작업 화면에는 본 선택 버튼이나 새 도구줄을 추가하지 않는다. 안내선 표시는 기존 스위치를 사용한다.

참고 형태는 st.freeReference에 독립적으로 복사하며 st.target은 빈 값이다. 따라서 도전의 횟수 제한·점수·붕괴·도전 결과·기록 보상 계산에 들어가지 않는다. 안내선은 기존 점선 렌더링을 사용하고 화면 맞춤은 실제 흙과 참고 형태를 함께 고려한다. 현재 작업 저장 상태에 참고 형태와 표시 여부가 포함되어 앱을 다시 열어 이어할 수 있다. 새 작업이나 도전은 참고 형태를 초기화한다. 기존 튜토리얼 화면에는 새 선택기를 노출하지 않는다.

모바일은 헤더 아래 기존 상단을 한 줄로 유지한다. 새 본 선택 버튼을 작업 상단에 넣지 않으므로 선택한 본의 이름 길이와 무관하게 상단이 늘어나지 않는다. 참고 본 유무에 따라 상단 높이가 늘지 않는지, 기존 정보와 보기 전환이 한 줄인지 자동 검증한다.

Chrome 320·390·830·1440·2560px 화면에서 처음 선택창, 기본 14개 선택, 실제 점선 그리기/끄기, 24회 연속 편집, 개인 본 선택, 선택 취소 시 작업 보존, 재실행 후 이어하기, 꾸미기 이동과 빚기 복귀, 도전 점수 표시의 독립성을 검증한다. 별도로 기존 개인 도전 등록·공유와 튜토리얼, 제작부터 완성까지 기본 흐름을 확인한다. 실제 휴대전화 하드웨어 검증은 아니다.
