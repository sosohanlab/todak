# 토닥 제작·모바일 안내 수정 목록
기준: GitHub main `0883223af8bf5528330fe92c2a31770d8f4ee342` 이후 비공개 테스트에서 검수한 변경입니다. 기록 날짜: 2026-11-18 (한국 시간).

## 빚기·깎기·두께
- 정지 접촉으로 모양이 임의로 변하는 문제와 짧은 드래그가 반영되지 않던 문제를 수정했습니다.
- 주변 반경을 한 점으로 끌어당기던 계산을 정리해 의도하지 않은 울퉁불퉁함을 줄였습니다.
- 단면 양쪽에서 안쪽 두께를 조절할 수 있고, 외곽·바닥 두께를 보존합니다.
- 모양 잡기로 돌아오면 손끝 범위를 기본 보통으로 돌립니다.
- 모양·속 두께·깎기와 붓·도장·조각칼·지우개·유약 붓의 크기를 작업 위치에 윤곽으로 표시합니다.
- 깎기에 밑바닥 편집을 추가했습니다. 실제 밑면을 파서 굽을 남기며, 원래 외벽·내벽과 안전 두께를 보존합니다.
- 겹친 원판/링 오버레이가 만든 가짜 동심원 줄무늬와 끊어진 반사 띠를 정리했습니다.
- 접시 윗면의 음각·양각·지우개를 연결하고 저장·이어하기·되돌리기에서 유지합니다. 윗면 새김은 완성 3D에서 얕은 표면 효과입니다.

## 유약·사진·저장
- 유광/무광 명칭과 표면 구분, 잔금과 입구/내벽 표현, 입구 흰 반사광을 보정했습니다.
- 담그기에 위에서/아래에서 방향과 기울기를 추가했습니다. 외벽·내벽·입구·밑바닥에 같은 평면을 적용합니다.
- 대표 색상과 직접 색/코드 선택은 유지하며 기존 그림·도장·조각·유약 범위를 보존합니다.
- 새 작품을 만들면 이전 유약·무늬·도구 설정을 초기화하고, 이어하기에서는 하던 작업을 복원합니다.
- 360도 감상 중 배경 변경이 별도 배경층에 바로 적용되도록 했습니다.
- 도전 본 버튼은 ‘이 작품으로 / 도전 본 만들기’ 단위로 줄바꿈합니다. 완성 화면의 ‘뭘 닮았을까?’를 앞쪽으로 배치하고 강조했습니다.

## 모바일·튜토리얼
- 컵 안내선으로 처음 제작을 연습하고 모양 잡기 → 깎기 → 속·두께 → 매끈하게 및 꾸미기·유약·굽기·감상·저장을 실제 동작으로 설명합니다.
- 모바일은 두 손가락 확대·축소, PC는 마우스 휠을 안내합니다.
- 자유 작품의 도전 본 등록과 코드/링크 공유 방법을 설명합니다.
- 설명용 다음 버튼을 연속으로 누르게 하지 않고, 단계 끝에서 충분히 연습한 뒤 실제 다음 단계로 이동합니다.
- 모바일의 중복 진행표를 줄이고 접힌 도구창은 한 줄로 정리했습니다. 접힘/펼침처럼 페이지 가용 공간이 변해도 작업과 진도를 유지합니다.
- 도구를 고르자마자 창이 닫히며 도자기가 약 1.5배로 커지던 문제를 수정했습니다. 이제 직접 ‘도구 접기’를 누릅니다.
- 선택할 버튼·슬라이더 자체가 천천히 깜빡입니다. 버튼 아래 추가 안내 글상자, 긴 연결 화살표, 화면 어둡게 처리는 사용하지 않습니다.
- 한 번에 현재 항목만 강조하고, 조작 중/홈 이동 때는 해제합니다. 동작 줄이기 설정에서는 고정 테두리를 사용합니다.
- 옆모습/윗모습/밑바닥과 회전 버튼을 구분하고, 위·밑 시점에는 같은 작품의 옆모양을 함께 보여 줍니다.
- 불필요한 보기 글자, 치수 표시, 흙덩이 버튼과 튜토리얼 안의 홈으로 링크를 숨겼습니다.

## 유지한 기능과 한계
- 기존 사진 최적화·캐시, 자유로운 360도 회전 조작, 원래 작품 데이터와 저장 기능을 유지합니다.
- Supabase 스키마·설정·사용자 데이터는 변경하지 않았습니다. 기존 작품을 삭제/이관하지 않습니다.
- 밑바닥과 담그기 방향은 선택 필드입니다. 필드가 없는 기존 작품도 불러올 수 있습니다.
- 쉬운 난이도와 손빚기 기능은 이 변경에 추가하지 않았습니다.
- 참고 사진 수준의 사실감과 2차 스튜디오 조명은 아직 완료로 판정하지 않았습니다.
- 모바일 검사는 PC Chrome의 화면 크기·터치 에뮬레이션입니다. 실제 Galaxy Fold/Android/iPhone 하드웨어 검증은 별도입니다.

검수 및 다시 실행하는 방법은 [VALIDATION.md](VALIDATION.md)를 참고하세요.
