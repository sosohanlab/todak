# 검수 결과
## 독립 빌드
기존 GitHub 파일 목록을 기준으로 격리한 소스에서 일반 공개 빌드 경로를 실행했습니다. 비공개 테스트에서 검수한 실행 파일 78개의 내용이 재생성 결과와 모두 일치했습니다.

## 실행한 검사
- PC 마우스/모바일 터치: 37개 튜토리얼 실습 및 마지막 PNG 다운로드, 진도 이어하기 통과.
- 390×520 / 360×640 / 720×620 × 7도구: 도구 선택 후 창 유지, 실제 터치 조절, 직접 접기/다시 열기 21사례 통과. 도구 선택 전후 표시 배율 1.000.
- 390×520 / 720×620 / 1440×900: 깎기 버튼의 실제 시간별 깜빡임, 다음 슬라이더로 강조 이동, 홈에서 해제, 추가 글상자 없음 통과.
- 동작 줄이기: 깜빡임 없이 고정 테두리 유지.
- 접시/그릇/컵/항아리: 정지 접촉/짧은 이동/좌우 두께 및 기본 손끝 크기 복귀 18사례 통과.
- 밑바닥 깎기: 정지 무변형, 실제 밑면 메시 반영, 굽 테두리·외벽·내벽 보존, 저장/불러오기/구간별 되돌리기 통과.
- 위/아래 담그기 × -45/0/45도: 외벽 마스크 불일치 0, 실제 GPU 셰이더, 내벽/밑바닥, 저장/이어하기 통과.
- 기존 작품 5개, 360도 불러오기, 원형 저장 데이터 보존 및 1080×1500 PNG 실제 다운로드 통과.
- Worker/WebGL 실패 시 기존 Canvas 대체와 PNG 저장 통과.

## 렌더링 비용 참고
같은 컵/굽 잔을 각 40회 그린 PC Chrome 비교에서 화면 폭 1440의 p95는 18.9→9.9ms, 17.3→9.2ms였습니다. 폭 390은 9.0→3.5ms, 8.1→3.4ms였습니다.
강제 작은 픽셀 readback을 포함한 2D 표면 그리기 시간입니다. 전체 조작 FPS나 실제 휴대폰 성능 수치가 아닙니다. 이번 변경 뒤 장시간 GPU 메모리 안정성을 새로 측정한 것은 아닙니다.

## 재실행
저장소 복사본에서 다음 순서로 실행합니다. 운영 서비스/Supabase에 쓰지 않으며, 테스트 작품과 브라우저 저장소는 격리됩니다.
```sh
npm install --no-save playwright
npx playwright install chromium
node tools/build-public-release.cjs
node tools/workshop-qa/check-pulse.cjs
node tools/workshop-qa/check-saved-works.cjs
```
기본 검사 대상은 release-site입니다. 다른 디렉터리는 TODAK_QA_ROOT로 지정할 수 있습니다. Chrome 채널을 쓰려면 TODAK_BROWSER_CHANNEL=chrome, 별도 Playwright 설치는 TODAK_PLAYWRIGHT_PATH로 지정합니다.
결과와 PNG는 운영체제 임시 디렉터리의 todak-workshop-qa에 기록합니다.

이번 GitHub 반영용 소스에서도 위 두 검사를 다시 실행했습니다. 다른 실습/입력/담그기 검사는 동일한 실행 파일을 사용한 개발 검수 결과입니다. 실제 휴대폰 하드웨어 검사는 하지 못했습니다.
